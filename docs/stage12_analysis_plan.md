# Stage 12 analysis plan · GSE125583 fusiform gyrus

Recorded before calculating correlations. The estimand is a common, within-cohort partial association between transformed abundances after linear adjustment for diagnosis, age and sex. Analyze the brain cohort alone.

1. Require exact ordered GSMs, distinct case codes, disjoint unique Entrez gene axes, Stage 10 eligible annotation categories, zero missing counts and cell-for-cell identity with the original integer TSV. Reconcile the Stage 11 primary and severe-QC masks with metadata and QC rules. Retain all complete primary cases regardless of flags. Use the saved sensitivity subset and report all exclusions.
2. For each fit estimate positive-count median-ratio size factors on all raw genes, geometrically centered to one, using the installed PyDESeq2 poscounts convention. Compare with corresponding saved Stage 11 lncRNA-only factors by GSM. Report factor correlation, medians by diagnosis and by any QC flag, plus descriptive joint regression of log2(whole / lnc-only) on diagnosis, age, sex and flag status with HC3 confidence intervals. No threshold or sample selection depends on these comparisons.
3. Freeze genes with at least 10 counts in at least 10 primary samples. Exclude constant raw features in primary. Analyze log2(1 + count / size factor). Remove fitted intercept, AD indicator, centered age and sex by QR projection. Mark any numerically constant residual columns separately in each fit. Treat missing values as an input error. Cell fractions, RNA integrity and postmortem interval are unavailable in saved model metadata. Braak score is a pathology measure. Do not substitute it for a cell fraction.
4. Compute Pearson correlations of normalized residual vectors in row blocks. For n cases and covariate design rank k including intercept, use the two-sided t test with n−k−1 df. This uses independent subjects, a linear covariate model and approximately Gaussian residuals; outliers, nonlinearities and correlated gene tests limit inference. Compute exact global BH across every valid pair within each fit, including both signs. Primary significance q<0.05. For stability count same-sign edges passing q<0.05 in both fits, sign reversals, gains and losses. Store both fits in one compressed Parquet with Entrez IDs and r, p and q.
5. Export a compact edge summary with up to three strongest primary positive and three strongest primary negative edges per lncRNA among same-sign, doubly significant edges. For the display network use up to four lncRNAs with strongest reproducible magnitude and up to two partners per lncRNA. Figures are descriptive. Pair inference precedes ranking. DE results play no role in eligibility or ranking.
6. For enrichment define a separate foreground per lncRNA and direction using doubly significant, same-sign pairs with absolute r at least 0.75 in both fits. Export all memberships and the eligible, tested coding background. Test lists containing at least 10 genes against local NCBI GRCh38.p13 GO Biological Process memberships of size 15–500 within the measured primary coding universe. Include unannotated measured genes in the denominator; quantify annotation loss. Use the actual GeneID and GOProcessID fields, with no inferred ancestor annotations. Treat the exact SHA256 of the local file as its snapshot version; a GO ontology release date is unspecified. One-sided hypergeometric overrepresentation, global BH over all qualifying list–term combinations including zero overlaps. GO process associations may reflect cell mixtures or broad expression programs. No external services. If no usable mappings exist, export lists and report the blocker.
7. Validate global BH and partial-correlation p-values against small independent reference fits, as well as file contents, sample masks, projection counts and output identities. Fixed display choices, no random analytical sampling. Report biological limitations and stop after Stage 12.
