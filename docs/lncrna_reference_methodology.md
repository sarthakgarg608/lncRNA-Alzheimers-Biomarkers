# Stage 10 reference and mapping methodology

The GENCODE header identifies GRCh38, version 50 and Ensembl release 116. Script 06 reads all nine GTF fields, selects gene-level records and retains versioned ENSG, stable ENSG, symbol, biotype, chromosome, 1-based inclusive start and end, strand, assembly and releases. Removing the numeric version for a cross-reference preserves a pseudoautosomal suffix. Among 37,560 gene records, 36,476 have the gene biotype `lncRNA` and 1,084 have `TEC`. Only the former enter the reference. The supplied GTF contains 197,195 transcript and 730,753 exon records. Repeated gene symbols are permitted. Duplicate stable gene IDs stop the build.

The companion transcript FASTA covers 670,670 transcripts from 86,411 versioned gene IDs. The parser checks transcript IDs and header lengths against sequence lengths and records the observed transcript-type distribution. The gene catalog retains all observed transcript types, including coding and pseudogene transcripts. A transcript type alone does not establish an lncRNA gene assignment. The sequence scanner uses one transcript at a time. Source-specific field names, record counts, missing fields, duplicate IDs, assembly details and full SHA256 digests are in [the annotation source manifest](../outputs/tables/stage10/annotation_sources.json).

## Blood evidence

Measured probe IDs come from the Stage 09 Parquet feature axis. Joining on the platform ID retains every measured probe, including controls and unassigned probes. The GPL10558 and GPL6947 coordinate columns refer to NCBI build 36 version 3. Stage 10 uses their nucleotide sequences, uppercased without changing bases. The GPL15988 table supplies nuID and accession/symbol/description fields. Its supplementary folder contains cached web assets. The nuID itself encodes the oligo. The decoder checks the mod-21 checksum, padding count and padded bases. On GPL6947 all 48,802 records with both a nuID and a sequence decoded to the supplied sequence, case-insensitively. Each external feature can therefore be compared by its actual bases. [Bioconductor lumi manual](https://www.bioconductor.org/packages/release/bioc/manuals/lumi/man/lumi.pdf) · [Author's id2seq implementation](https://rdrr.io/bioc/lumi/src/R/id2seq.R)

The local C++ scanner searches each distinct measured A/C/G/T 50-mer and its reverse complement against every transcript. Three disjoint 16-base seeds start at offsets 0, 17 and 34. With at most two substitutions at least one seed must match exactly. The scanner verifies all 50 positions after each seed hit and keeps the minimum distance per sequence and gene across isoforms. The headerless evidence table `sequence_hits.tsv` has six fields in order: uppercased probe sequence, versioned ENSG, minimum substitutions, one supporting ENST, strand relative to transcript sequence and that transcript's biotype. Tied transcripts within a gene contribute one representative. Search hits cannot cross transcript boundaries.

A validated probe requires a full-length, forward exact transcript match to a GTF lncRNA gene, a single target gene across both orientations through two substitutions and compatible available platform and NCBI evidence. A current symbol can identify multiple genes. Conflicting stable gene links, known coding accessions, incompatible NCBI gene categories and multiple sequence targets are retained for review. A reverse-only match or near match alone cannot validate a measurement. The threshold is an operational transcriptome-specific rule. The scan does not estimate binding thermodynamics or cover indels, arbitrary partial matches, individual variants, unannotated loci or genomic DNA. The resulting inventory records computational probe specificity.

`NON_LNCRNA` requires a unique forward exact gene assignment with positive transcript evidence for a different category. `PROVISIONAL` covers incomplete unique assignments. `AMBIGUOUS` covers conflicts or multiple plausible targets. `UNMAPPED` covers probes without a linked modern gene. Candidate counts include any historical or sequence link to an eligible gene, across confidence categories. Probes remain separate assay features. Identical sequences and genes are required for the strict overlap count. Concordance is descriptive Pearson correlation between separate validated probes of a gene across the cohort. No aggregation or concordance-based selection is applied.

## Brain evidence

Script 08 compares the original Entrez-indexed raw count TSV with the Stage 09 matrix before projection. It joins on GeneID and follows only the explicit EnsemblGeneID field in the NCBI GRCh38.p13 annotation. Symbols and genomic coordinates are never join keys. The NCBI release date and a patch-level identifier for the GENCODE input are unspecified in the local source headers.

An active NCBI ncRNA with an unambiguous link to a GENCODE lncRNA qualifies unless a specific short RNA description contradicts it. An explicit NCBI long RNA description can qualify independently. Generic ncRNA, gene length, antisense naming and an absent GENCODE match alone are insufficient. Host-gene descriptions are distinguished from the short RNA products. Inactive records, shared crosswalk targets, uninformative types and conflicting biotypes remain unresolved. Protein-coding and other specific RNA categories retain their NCBI evidence. GeneID remains the count matrix key even when Ensembl evidence is available.

Brain and blood matrices retain separate sample axes. Column projection preserves the original stages' intensity or integer count values, sample order and all QC-flagged samples. No randomness enters the annotation.
